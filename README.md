# KaloriVision AI

Flutter Android calorie and nutrition tracker.

## Features
- Daily calorie dashboard and macro totals
- Manual meal entry and local history
- Food photo analysis using Gemini with a user-provided API key
- Barcode scanning with Open Food Facts lookup
- Daily calorie goal settings

## Build APK
Open Actions, select Android APK Build, then Run workflow. Download the KaloriVision-AI-APK artifact after the workflow succeeds.

## AI analysis
Add your own Gemini API key in Settings. Photos are sent to Gemini only when you explicitly request analysis. Calorie and macro results are estimates.

## Privacy
Meal history and settings are stored on the device. Never share your API key.
